# Antigravity Rule: Anti-AI Design Aesthetics

When generating or refactoring UI components, pages, CSS styles, or web applications, the agent MUST enforce the following taste standards:

1. **Aesthetic Philosophy**: Create bespoke, human-crafted interfaces. Avoid boilerplate templates.
2. **Forbidden Clichés**:
   - Never use neon purple or cyan glows on dark backgrounds unless explicitly requested.
   - Never use pulsing badge pills with sparkle emojis right above headlines.
   - Never apply multi-color text gradients (`bg-clip-text text-transparent`) across hero keywords.
   - Never cram cards with random 3D icons or generic bento boxes.
3. **Typography & Layout**:
   - Enforce curated font pairings (Editorial Serif or Neo-Grotesque Display + Clean Sans Body).
   - Use tight negative letter-spacing on display headlines (`tracking-tight`).
4. **Motion & Interaction**:
   - Use spring physics transitions (`framer-motion`) with mass, stiffness, and damping.
   - Add tactile micro-interactions (press-down states, hover reveals, fluid toasts via `sonner`).

# AGENTS.md — Universal Agent Taste Directive

## Mission
You are acting as a Senior Design Engineer. Every component, page, or layout you output must adhere to high-craft human aesthetic standards.

## Code Standards
- **Imports**: Import icons from `lucide-react`, animations from `framer-motion`, toasts from `sonner`, and utilities from `@/lib/utils`.
- **Class Merging**: Always use `cn()` when combining class strings or conditionally toggling styles.
- **Accessibility**: Use semantic HTML5 elements (`<main>`, `<header>`, `<article>`, `<nav>`, `<button>`) and ARIA labels.

## Visual Taste Rules
1. **Typography**: Large headlines must use `tracking-tight` or `tracking-[-0.03em]`.
2. **Spacing**: Avoid cramped containers; give elements room to breathe with balanced padding (`p-6` to `p-12`).
3. **Surfaces**: Give containers depth with subtle border contrasts (`border border-border/60`) and tactile shadows (`shadow-tactile-sm` or `shadow-tactile-md`).
4. **Copywriting**: Avoid marketing fluff. Write direct, confident, human sentences.
